Privacy Policy — MoneyMinute Agent

Last updated: 31 October 2026

MoneyMinute Agent is a private automation tool used only by the owner of the MoneyMinute Bharat YouTube channel to prepare and upload videos to that channel. It is not offered to the public.

What it accesses

With the owner's permission (Google sign-in), the tool uses the YouTube Data API to upload videos and set thumbnails on the owner's own channel. It does not read, collect or store any data about other YouTube users or viewers.

What it stores

A sign-in token is kept as an encrypted secret in the owner's private GitHub repository so the upload can run automatically. No personal data is sold, shared or used for advertising.

Google API Services

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can revoke access at any time from Google Account → Third-party access.
